# قائمة اختبارات الجهاز

[English](TESTING.md) · [فارسی](TESTING.fa.md) · [Русский](TESTING.ru.md) · [العربية](TESTING.ar.md)

استخدم جهازاً احتياطياً أو فترة صيانة مع إبقاء مسار الإدارة متاحاً. لا تستبدل تثبيت `test1` قديماً يعمل. احتفظ ببيانات الحساب محلياً.

سجّل كل بند بوصفه **ناجح / فاشل / لم يُختبر**. لا تختصر النتيجة إلى «يعمل» إن تخطيت بعض البنود.

1. تسجيل الطراز الدقيق ومراجعة العتاد والمعالج وبناء البرنامج الثابت ونسخة الحزمة.
2. التحقق من بصمة الأرشيف واختيار معمارية المعالج الصحيحة.
3. نجاح `install.sh --check` مع `--experimental` عند الحاجة.
4. اكتمال التثبيت الجديد؛ ميّز إعادة التثبيت أو الترقية في التقرير.
5. بدء الخدمة وفتح Services → Firefox VPN عبر إدارة LAN IPv4.
6. نجاح دخول Mozilla واختبار Test connection.
7. تعطيل Localhost Proxy في PassWall2 وعدم وجود VPN أو مسار بيانات بديل لدى عميل LAN.
8. نجاح التصفح عبر العقدة المختارة؛ تسجيل أعطال DNS منفصلة.
9. نجاح طلب جديد بعد الخمول أو Sleeping.
10. حفظ الحسابات وعودة التصفح بعد إعادة تشغيل الخدمة.
11. عودة الخدمة وتصفح LAN بعد إعادة تشغيل الجهاز دون تشغيل النواة يدوياً.
12. اختياري: حفظ الحسابات بعد إعادة التثبيت؛ إزالة الخدمة والقائمة مع حفظ الحسابات عند الإزالة. اختر عقدة أخرى قبل الإزالة.

لا ترفق عنوان IP عاماً دقيقاً أو اسم المضيف أو اسم Wi-Fi أو MAC أو الرقم التسلسلي أو البريد أو كلمات المرور أو الرموز أو أكواد التحقق أو نسخ الحسابات أو السجلات الكاملة. يعرض التشخيص حقولاً مسموحاً بها فقط؛ راجع المخرج قبل مشاركته. لا تُجمع بيانات تتبّع.

[أرسل التقرير](https://github.com/maroufshahram-bot/firefox-vpn-openwrt-fa/issues/new/choose). تُقبل العربية والروسية والفارسية والإنجليزية. يراجع المشرف الأدلة قبل تغيير حالة التوافق. نجاح اختبار واحد يخص التركيبة الدقيقة ولا يعتمد العلامة التجارية بأكملها.
