# Проверка на устройстве

[English](TESTING.md) · [فارسی](TESTING.fa.md) · [Русский](TESTING.ru.md) · [العربية](TESTING.ar.md)

Используйте запасной роутер или окно обслуживания с рабочим каналом управления. Не заменяйте работающую старую установку `test1`. Сохраняйте аккаунты локально.

Для каждого пункта укажите **успех / ошибка / не проверено**. Не пишите просто «работает», если часть шагов пропущена.

1. Записаны точная модель, аппаратная ревизия, CPU, сборка прошивки и версия пакета.
2. Проверена контрольная сумма и выбран правильный CPU-архив.
3. Пройден `install.sh --check` с `--experimental`, если требуется.
4. Первичная установка завершена; повторную установку/обновление укажите отдельно.
5. Служба запускается; Services → Firefox VPN открывается через LAN IPv4.
6. Успешны вход Mozilla и Test connection.
7. Localhost Proxy в PassWall2 выключен; у клиента LAN нет другого VPN или канала данных.
8. Браузинг LAN работает через выбранный узел; ошибки DNS записаны отдельно.
9. После простоя/Sleeping новый запрос проходит.
10. Перезапуск службы сохраняет аккаунты и восстанавливает браузинг.
11. После перезагрузки роутера служба и браузинг LAN восстанавливаются без ручного запуска ядра.
12. Необязательно: переустановка сохраняет аккаунты; удаление убирает службу и меню, сохраняя аккаунты. Перед удалением выберите другой узел.

Не публикуйте точный публичный IP, имя хоста, SSID, MAC, серийный номер, почту, пароли, токены, коды проверки, резервные копии аккаунтов или полные журналы. Диагностика выводит только разрешённые поля, но её вывод тоже нужно проверить. Телеметрия не собирается.

[Отправить отчёт](https://github.com/maroufshahram-bot/firefox-vpn-openwrt-fa/issues/new/choose). Принимаются русский, арабский, персидский и английский. Перед изменением совместимости сопровождающий проверяет доказательства. Успех относится только к конкретной комбинации, а не целому бренду.
