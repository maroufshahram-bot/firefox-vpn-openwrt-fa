# Совместимость

[English](COMPATIBILITY.md) · [فارسی](COMPATIBILITY.fa.md) · [Русский](COMPATIBILITY.ru.md) · [العربية](COMPATIBILITY.ar.md)

Совместимость относится к сочетанию **модели + аппаратной ревизии + прошивки + пакета**. Совпадение бренда или процессора её не подтверждает.

## Имеющиеся результаты

| Устройство / среда | Результаты | Статус установщика |
| --- | --- | --- |
| Google WiFi (Gale), ARMv7, ipq40xx/chromium, OpenWrt 25.12.1 r32768-b21cfa8f8c, Linux 6.12.74 | Владелец сообщил об успешном входе, тесте соединения, пункте LuCI, браузинге через PassWall2 и работе после перезагрузки с ядром приложения 1.0.5 | Новый комплексный установщик не проверен на устройстве |
| Любая другая модель, ревизия или прошивка | Проверенного отчёта в репозитории нет | Экспериментально; требуется явный параметр согласия |

Распознавание эталонной модели, версии, target и CPU установщиком не означает прохождения испытаний этого кандидата в релиз. Подтверждённая совместимость по отчётам сообщества пока не добавлена.

## Архивы процессоров

| Суффикс | Ожидаемый CPU | Примечание |
| --- | --- | --- |
| linux-armv7 | 32-бит ARMv7, `armv7l` | Архитектура эталонного Google WiFi |
| linux-arm64 | 64-бит ARM, `aarch64` | Экспериментально |
| linux-amd64 | x86-64, `x86_64` | Экспериментально |
| linux-mips | 32-бит MIPS, big-endian | Экспериментально; программная плавающая точка |
| linux-mipsle | 32-бит MIPS, little-endian | Экспериментально; программная плавающая точка |

Матрица сборки задаёт цели, но не доказывает успешность каждого запуска. Проверяйте конкретный результат. ARMv5/v6, 32-бит x86, MIPS64 и другие неподдерживаемые CPU отклоняются. Ядро MIPS может сообщать `mips` при любом порядке байтов; установщик дополнительно выполняет локальный `-version` и отклоняет неработающий файл. Сеть и аккаунты при этой проверке не используются.

## Примеры роутеров

Таблица помогает выбрать архив на **уже установленной совместимой системе семейства OpenWrt**, но не подтверждает работу пакета. Архитектуры сверены с данными OpenWrt 2026-10-30.

| Точная модель | Кандидат | Источник и ограничение |

| GL.iNet GL-MT6000 (Flint 2) | linux-arm64 | [Данные OpenWrt](https://openwrt.org/toh/hwdata/gl.inet/gl.inet_gl-mt6000); испытание пакета ожидается |

Запускайте предварительную проверку на самой системе. Заводская ОС, другая ревизия, нехватка места или зависимостей могут сделать даже правильный выбор CPU недостаточным.

## Прошивки

| Семейство | Статус | Условия |
| --- | --- | --- |
| OpenWrt | Эталонная платформа; остальные сочетания экспериментальные | LuCI, procd, ubus, jsonfilter, IPv4 LAN и достаточно места |
| ImmortalWrt | Экспериментально | Те же службы; испытаний устройств пока нет |
| Заводская прошивка GL.iNet | Экспериментальный кандидат | Должна определяться как допустимое семейство OpenWrt и иметь необходимые службы; особенности моделей не проверены |
| Asuswrt-Merlin, DD-WRT, RouterOS и другие заводские ОС вне этого семейства | Установщик не поддерживает | Нужна отдельная интеграция; не обходите проверки |

## Приоритеты тестирования

Нужны тесты точных моделей и ревизий с поддержкой OpenWrt: GL.iNet (включая Flint/Slate), Xiaomi/Redmi, TP-Link, Cudy, затем x86-64. Это **направления поиска тестировщиков, а не список поддерживаемых устройств**. Не прошивайте устройство на основании списка; сначала проверьте официальную документацию проекта прошивки.

Укажите модель, ревизию, сборку прошивки, CPU, пакет, preflight, первичную/повторную установку, вход, браузинг LAN, сон/пробуждение, перезапуск службы и перезагрузку. См. [список тестов](TESTING.ru.md). Таблица результатов меняется после проверки сопровождающим.
