# التثبيت

[English](INSTALL.md) · [فارسی](INSTALL.fa.md) · [Русский](INSTALL.ru.md) · [العربية](INSTALL.ar.md) · [التوافق](COMPATIBILITY.ar.md)

## قبل البدء

- يلزم برنامج ثابت من عائلة OpenWrt مع LuCI وprocd، ومعمارية مدعومة، وصلاحية root، ومساحة تخزين دائمة حرة لا تقل عن 40 ميغابايت؛ قد تحتاج الملفات الأكبر إلى مساحة إضافية.
- يلزم حساب Mozilla / Firefox والوصول إلى بريده وإتمام أي تحقق مطلوب.
- يجب أن يتصل الموجّه بالإنترنت. لا يُضمن توفر الحساب أو الخوادم.
- ثبّت PassWall2 بصورة منفصلة لتوجيه أجهزة LAN عبر الوكيل.
- احتفظ بطريقة للعودة إلى عقدتك العاملة. لا يغيّر المثبّت الجدار الناري أو الشبكة أو DNS أو إعدادات PassWall2.

لا تثبّت فوق نسخة `test1` قديمة تعمل؛ لا يتوفر ترحيل تلقائي. لم يُختبر المثبّت الجديد على موجّه فعلي بعد.

**لغة المثبّت:** تدعم الشيفرة الخيارات `--lang en` و`fa` و`ru` و`ar`. تحتوي أرشيفات **v0.2.0-rc.1** المنشورة على المثبّت السابق؛ استخدم `en` في الأوامر أدناه. مع بناء جديد يتضمن الترجمة، استبدل `--lang en` بـ `--lang ar`. لا تستبدل ملفات منفردة داخل الأرشيف القديم.

## ١. الاتصال بالموجّه

استخدم SSH من حاسوب أو هاتف أو جهاز آخر:

</div>

```sh
ssh root@ROUTER_ADDRESS
```

<div dir="rtl">

استبدل `ROUTER_ADDRESS` بعنوان موجّهك محلياً ولا تنشره. يمكن استخدام طرفية LuCI إن كانت مثبّتة. استخدم LAN موثوقة أو مسار إدارة آمناً موجوداً؛ لا حاجة لفتح منافذ WAN.

## ٢. التنزيل والتحقق والنقل

اختر أرشيف المعالج الصحيح من بناء ناجح أو إصدار راجعته، ونزّل ملف `.sha256` المطابق. في مجلد التنزيل على الحاسوب:

</div>

```sh
sha256sum -c firefox-vpn-openwrt-v0.2.0-rc.1-linux-armv7.tar.gz.sha256
```

<div dir="rtl">

المثال لـ ARMv7؛ غيّر اسم الملف للمعمارية الأخرى. تتحقق البصمة من سلامة الملف، ولا تثبت وحدها موثوقية الناشر.

انقل الأرشيف إلى `/root` عبر مدير ملفات LuCI أو WinSCP أو SCP:

</div>

```sh
scp firefox-vpn-openwrt-v0.2.0-rc.1-linux-armv7.tar.gz root@ROUTER_ADDRESS:/root/
```

<div dir="rtl">

إذا أبلغ OpenSSH عن غياب SFTP، فاستخدم `scp -O` أو طريقة نقل أخرى. لا ترفع الأرشيف إلى Flash Firmware أو Restore Backup أو مدير الحزم.

## ٣. الفحص المسبق

على الموجّه، فك الأرشيف ثم افحص:

</div>

```sh
cd /root
tar -xzf firefox-vpn-openwrt-v0.2.0-rc.1-linux-armv7.tar.gz
cd firefox-vpn-openwrt
sh install.sh --lang en --check
```

<div dir="rtl">

إذا اختلف الطراز أو إصدار البرنامج الثابت أو الهدف عن التركيبة المرجعية الدقيقة:

</div>

```sh
sh install.sh --lang en --experimental --check
```

<div dir="rtl">

لا يثبّت `--check` شيئاً. نجاحه لا يثبت التوجيه أو تسجيل الدخول أو التعافي بعد إعادة التشغيل أو التوافق. تُرفض العائلات خارج OpenWrt/ImmortalWrt حتى مع `--experimental`. يجب أن تعرّف نسخة GL.iNet نفسها كعائلة OpenWrt مقبولة وتوفّر الخدمات المطلوبة؛ العلامة التجارية وحدها لا تكفي.

## ٤. التثبيت

للمنصة المرجعية:

</div>

```sh
sh install.sh --lang en
```

<div dir="rtl">

للمنصة التجريبية بعد قبول قيودها صراحة:

</div>

```sh
sh install.sh --lang en --experimental
```

<div dir="rtl">

تُحفظ الحسابات الحالية. يربط التثبيت الجديد وكيل SOCKS بـ `127.0.0.1:10810` ولوحة HTTP بعنوان LAN IPv4 على المنفذ `10820`. لا تُعاد كتابة الإعدادات الحالية؛ راجع عناوين الاستماع. عند فشل التثبيت بعد استبدال ملفات البرنامج، يحاول المثبّت استعادة الملفات السابقة. هذه ليست نسخة احتياطية كاملة للموجّه ولا ترحيلاً.

اقرأ بيانات الدخول الأولية محلياً:

</div>

```sh
cat /etc/firefox-vpn/initial-login.txt
```

<div dir="rtl">

لا تنشر هذا المخرج أو بيانات الحساب أو لقطة طرفية دون إخفاء الأسرار. تُولّد كلمة مرور عند أول تثبيت وتُحفظ عند إعادة التثبيت.

## ٥. إضافة حساب

حدّث LuCI وافتح **Services → Firefox VPN** عند الوصول إلى LuCI بعنوان LAN IPv4. تُفتح لوحة HTTP في علامة التبويب نفسها. لا يغطي هذا التكامل الإدارة عبر IPv6 فقط أو الوصول عبر مسار وكيل عكسي.

سجّل الدخول ببيانات اللوحة، ثم اختر **Accounts → Add account** وأكمل تحقق البريد أو المصادقة الثنائية أو CAPTCHA. اختر **Test connection**. تعني `Connection OK` نجاح طلب الاختبار، وليست قياساً لزمن الاستجابة. بيانات دخول اللوحة والوكيل وحساب Mozilla منفصلة.

## ٦. إعداد PassWall2

**قبل اختيار عقدة Firefox، عطّل Localhost Proxy في PassWall2 → Basic Settings ثم نفّذ Save & Apply.** وإلا قد يعود اتصال النواة الصادر إلى النواة نفسها. أبقِ توجيه عملاء LAN مفعّلاً. يؤثر هذا الخيار أيضاً في حركة الموجّه نفسه عند اختيار عقد أخرى، ولا يُستعاد تلقائياً.

في **Node List → Add**:

| الحقل | القيمة |
| --- | --- |
| Remarks | Firefox VPN |
| Type | Xray |
| Protocol | Socks |
| Address | 127.0.0.1 |
| Port | 10810 |
| Username / Password | بيانات الوكيل، وليست بيانات اللوحة أو Mozilla |
| TLS | Off |
| Transport | RAW (TCP) |
| Mux | Off |
| Chain Proxy | Close / Not use |

لقراءة بيانات الوكيل وحدها محلياً:

</div>

```sh
jsonfilter -i /etc/firefox-vpn/config.json -e '@.proxy.username' -e '@.proxy.password'
```

<div dir="rtl">

لا تشارك المخرج. احفظ العقدة واخترها في Basic Settings وطبّق. اختبر من جهاز LAN بعد تعطيل VPN الخاص به ومسارات الإنترنت البديلة. إذا فشل التصفح، ارجع إلى العقدة العاملة السابقة.

## التشغيل واستكشاف المشكلات

تستمر الخدمة بعد إغلاق الطرفية. قد تكون حالة `Sleeping` طبيعية بعد الخمول؛ يفترض أن يوقظها طلب فعلي أو Test connection. تشغيل الخدمة لا يثبت نشاط النفق أو توفر الإنترنت.

| العَرَض | ما يجب فحصه |
| --- | --- |
| تحذير حلقة أو انقطاع الإنترنت بعد اختيار العقدة | عطّل Localhost Proxy وأعد تشغيل النواة |
| تعمل اللوحة ولا يعمل تصفح LAN | بيانات الوكيل وقواعد LAN في PassWall2 وإعدادات DNS |
| Sleeping | أرسل طلباً فعلياً قبل الإبلاغ عن الفشل |
| Could not fetch | حالة الخدمة والوصول عبر LAN IPv4 وعنوان HTTP للوحة |
| UDP refused | النواة تدعم TCP فقط |
| غياب قائمة LuCI | حدّث LuCI وافحص مخرجات التثبيت وحالة الخدمة |

</div>

```sh
/etc/init.d/firefox-vpn status
/etc/init.d/firefox-vpn restart
sh /usr/lib/firefox-vpn/diagnose.sh
```

<div dir="rtl">

يعرض التشخيص حقول منصة محددة فقط، ولا يقرأ ملفات الحساب أو الإعدادات ولا يرفع شيئاً. راجع حتى هذا المخرج قبل نشره. احتفظ بمخرج `logread` الكامل سرياً وشارك فقط المقتطف المناسب بعد تنقيحه يدوياً.

اتبع [قائمة الاختبار](TESTING.ar.md)، بما فيها إعادة التشغيل في وقت مناسب. لا تسجّل نجاح هذا الاختبار قبل عودة التصفح دون تشغيل النواة يدوياً.

## الإزالة

اختر عقدة PassWall2 أخرى تعمل أولاً، ثم من مجلد الأرشيف المفكوك:

</div>

```sh
sh uninstall.sh en
```

<div dir="rtl">

مع بناء جديد يتضمن الترجمة يمكنك استخدام `sh uninstall.sh ar`. تُحفظ الحسابات في `/etc/firefox-vpn`؛ لا تتوفر إزالة مدمّرة للحسابات. لا توجد تحديثات تلقائية للنواة؛ استخدم إصدارات المشروع المراجَعة، وليس محدّث سطح المكتب أو مثبّت Linux عاماً.

</div>
